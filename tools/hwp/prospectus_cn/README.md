# 대학원 중문 모집요강 만들기

국문 HWPX의 **글월만 중문으로 바꾸고 나머지(표·칸·테두리·쪽나눔)는 손대지 않는다.**
영문본(`../prospectus_gr`)과 같은 방식이고, 중문이라 다른 점만 아래에 적는다.

```
python mkcover_cn.py        # 표지·머리띠 그림
python mk_cn.py 1.0         # HWPX 생성 → PDF → 목차 쪽번호 보정 → PDF 다시
python mk_cn.py 1.0 --build # HWPX 까지만 (한글 변환이 막혔을 때)
```

## 영문본과 다른 점

| 갈래 | 영문본 | 중문본 |
|---|---|---|
| 본문 크기 | 0.80배로 줄임 | **원본 그대로(1.0)** |
| 절 제목 칸 | 영문이 길어 12칸 넓힘 | 손대지 않음(중문이 더 짧다) |
| 글꼴 | 맑은 고딕 그대로 | **HANJA 글꼴묶음 10개를 Microsoft YaHei 로 교체** |

중국어가 한국어보다 짧아 줄일 까닭이 없다. 사무처가 낸 학부 중문본도 국문과 같은
14쪽이고 Microsoft YaHei 로 조판돼 있어, 그 두 가지를 그대로 따랐다.

**한자 글꼴을 왜 바꾸나** — HWP는 글자가 어느 문자인지로 글꼴을 고르고, 중국어 한자는
'한자(HANJA)' 로 분류한다. 국문 원본의 한자 글꼴은 함초롬돋움이라 간체자(学·国·门 등)가
깨질 수 있다. `header.xml` 의 `lang="HANJA"` 글꼴묶음만 통째로 YaHei 로 바꾸면,
한글(사람 이름)은 맑은 고딕, 중국어는 YaHei 로 각각 제대로 나온다. 기호(※·○·∼)를
맡은 SYMBOL 묶음은 건드리지 않는다 — 바꾸면 기호 모양이 달라진다.

## 용어의 근거

사무처가 이미 낸 **학부 중문본**
(`…\2027학년도 모집요강\학부\…_중문본.pdf`, 2026-11-02)을 글자까지 그대로 따랐다.
같은 문장은 같은 말로, 대학원에만 있는 대목만 그 말씨에 맞추어 새로 옮겼다.

## 주임교수 이름 칸은 뺐다

11절 표 3개에서 **주임교수 이름 열을 통째로 뺐다**(`DROP_COLS = ['主任教授']`).
한자 표기를 확인할 수 없어 한글로 남았던 자리다. 칸만 지우면 표가 어긋나므로
`drop_column()` 이 뒤쪽 열의 `colAddr` 를 당기고 `colCnt` 를 줄이며, 뺀 너비(7600)를
왼쪽 专业 열에 더해 표 전체 폭 48000 을 그대로 지킨다. 가로 병합된 칸이 걸쳐 있으면
조용히 망가지지 않도록 멈춘다. 결과: `区分 | 专业 | 研究室(전화)` 3열.

## 한글로 남겨 둔 것

사람 이름(주임교수 35명), 장학금 고유명(호심·매원·백인), 건물명(호심관)은 **한자 표기를
확인할 자료가 없어 지어내지 않고 한글 그대로** 두었다. 연구실 명패와 서류도 한글이라
찾아가기에는 오히려 낫다. 확인되면 `trans_cn.py` 의 해당 줄만 고치면 된다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `trans_cn.py` | 국문→중문 사전 447개 (한글 든 글월 439개를 모두 덮는다) |
| `mk_cn.py` | HWPX 생성·PDF 변환·목차 보정 |
| `mkcover_cn.py` | 표지·머리띠 그림 (바탕판은 `../prospectus_en/img` 재사용) |
| `cn.hwpx` | 중문 HWPX (중간 산출물, 납품물은 PDF만) |
