# 광주대학교 외국인 신·편입생 입학 심사기준 정리

> 출처: `docs/reference/모집요강.pdf`, `docs/reference/외국인 유학생 입학서류 체크리스트 및 적합 기준.hwpx`
> 대상: 2026학년도 후기 외국인 신·편입생 특별전형

## 1. 전형 개요
- **전형방법**: 서류전형 100% (학업능력·어학능력·지원동기·인성 종합평가, 필요시 대면/화상 면접)
- **트랙**: 한국어트랙 / 영어트랙(일부 학과) / 중국어트랙(편입 일부 학과)
- **원서접수 일정**: 1차 2026.6.1~6.10, 2차 2026.6.22~7.1
- **문의 채널(국가별)**: 중국 2855 / 베트남 2779 / 영어 2288 / 몽골·기타 2569

## 2. 지원 자격 (선행 판정)
### 국적 요건
- 부모가 **모두** 외국인인 외국인
- 이중국적자·무국적자 → **부적합**

### 과정별 학력 자격
| 구분 | 적합 기준 | 확인 서류 |
|---|---|---|
| 신입학 | 한국 초·중등교육 상응 과정 전부 이수 졸업(예정)자 | 고교 졸업(예정)증명서, 성적표 |
| 편입 2학년 | 4년제 대학 1년 이상 수료(예정) | 재학·수료증명서, 성적증명서 |
| 편입 3학년 | 4년제 대학 2년 이상 수료(예정) 또는 전문대 졸업(예정) | 수료·졸업증명서, 성적증명서 |
| 편입 4학년 | 전문대 3년제 학과 졸업(예정), 동일계 전공 | 졸업증명서, 성적증명서(전공 일치) |

### 어학 자격 (입학 시)
| 과정 | 트랙 | 기준 |
|---|---|---|
| 신입 | 한국어 | TOPIK 3급↑ 또는 동등 (예체능 2급↑) |
| 신입 | 영어 | TOEFL IBT 59 / IELTS 5.5 / CEFR B2 / TEPS 600 / NEW TEPS 202 이상 |
| 편입 | 한국어 | TOPIK 3급↑ 또는 동등 (예체능 2급↑) |
| 편입 | 중국어 | 별도 기준 없음 (입학 후 한국어연수 200시간 이수) |

## 3. 제출서류 체크리스트
| No | 서류 | 필수여부 | 검토 포인트 |
|---|---|---|---|
| 1 | 입학지원서(소정양식) | 필수 | 지원서·유학계획서·자기소개서·유학경비부담서약서 + 개인정보동의서 서명 |
| 2 | 여권 사본 | 필수 | 본인 명의 일치, 판독 가능 |
| 3 | 여권용 사진 2장 | 필수 | 2장 제출 |
| 4 | 본인 신분증 사본 | 필수 | 여권과 인적사항 일치 |
| 5 | 부모 신분증 사본 | 필수 | 부모 모두 외국인 확인 |
| 6 | 가족관계증명서 | 필수 | 중국: 호구부 사본(2개↑ 시 친족관계증명서 공증본) / 기타국: 영문본 |
| 7 | 외국인등록증 | 해당자 | 국내 체류자 한함 |
| 8 | 최종학교 졸업·성적증명서 | 필수 | 신입: 고교↑ 졸업+성적 / 편입: 전문대↑ 학위·졸업·성적. **학위증명은 아포스티유 또는 영사인증 원본 + 학력인증보고서** |
| 9 | 재정보증서류 | 필수 | 보증금액 **1,600만원 이상** |
| 10 | 부모 재직·수입증명서 | 필수 | 재직·수입 증빙 |
| 11 | TOPIK 성적증명서 | 해당자 | 한국어트랙 기준 등급 충족 |
| 12 | 영어능력 성적증명서 | 해당자 | 영어트랙 기준 점수 충족 |

**공통 형식 기준**: 한국어·영어 외 언어 서류는 번역본 첨부 / 학위·학력 서류는 아포스티유·영사인증 필수

## 4. 자동검토 판정 로직
1. **자격 선행 판정**: 부모 중 1인이라도 한국 국적 → 부적합 / 이중·무국적 → 부적합
2. **학력 판정**: 지원 과정(신입/편입 학년)별 학력 기준 미달 → 부적합
3. **어학 판정**: 지원 트랙별 기준 미달 → 부적합
4. **서류 완비 판정**: 필수서류(1~6, 8~10) 누락 → 보완 요청 / 해당자 서류(7,11,12) 조건 확인
5. **형식 판정**: 아포스티유·영사인증 누락, 번역본 누락, 재정보증 1,600만원 미달 → 보완 요청
6. **최종 판정**: **적합 / 보완 필요(사유 명시) / 부적합(사유 명시)**
