# 광주대 대학원 외국인 특별전형 **서류심사표** (작업 중)

면접 없이 서류심사 100%인 대학원 심사표를 한글(.hwp) 파일로 만드는 작업.
한글 2022 COM 자동화(`HWPFrame.HwpObject`)로 표까지 그려서 저장한다.

## 파일
- `build_form.ps1` — 심사표 .hwp 생성 스크립트 (본체)
- `hwptext.js` — .hwp(OLE) 텍스트 추출기. 참고용 양식 읽을 때 사용
  `node hwptext.js "파일.hwp"`

## 실행 방법
UTF-8 BOM이 없으면 PowerShell 5.1이 한글을 깨뜨리므로 BOM으로 다시 써서 실행한다.

```powershell
$c = Get-Content -Raw -Encoding UTF8 .\build_form.ps1
[System.IO.File]::WriteAllText("$PWD\build_bom.ps1", $c, (New-Object System.Text.UTF8Encoding($true)))
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_bom.ps1
```

결과물: `바탕화면\★국제협력처\2. 대학원\심사표\광주대 대학원 서류심사표(초안).hwp`
(+ 검토용 preview.pdf 동시 저장)

## 지금 상태 — 남은 버그 하나
스크립트가 끝까지 돌지 못하고 `Font()`에서 **NullReferenceException**으로 멈춘다.
`$s.Bold = $bold` 에 `$bold`가 `$null`로 들어오는 Font 호출이 어딘가에 있다는 뜻.
어느 호출인지 잡으려고 `Font` 첫 줄에 진단용 `throw`를 넣어둔 상태(18행).
그대로 한 번 실행하면 **문제의 호출 위치가 메시지로 찍힌다** → 거기만 고치면 끝.

유력 용의자: 평가표 셀 입력 루프의 `Font 10 $c[2]`
(`$cells` 배열이 평탄화되면 `$c[2]`가 $null이 됨 → `$cells` 를 `,@(...)` 형태로 강제하거나
`Write-Host $c.Count` 로 확인)

## 이미 해결해둔 함정들
- 표 열 너비: `pset.ColWidth.SetItem(i, v)` 는 PowerShell에서 안 먹음.
  → `$cw.GetType().InvokeMember("Item", 'SetProperty', $null, $cw, @([int]$i, [int]$value))` 사용
- `SaveAs`는 보안 모듈 없이도 그냥 통과됨(대화상자 안 뜸)
- 셀 병합: `TableCellBlock` → `TableCellBlockExtend` → 방향 이동 → `TableMergeCell`
  병합은 **아래 행부터 위로** 처리해야 위쪽 좌표가 안 밀린다 (미검증 — 실행 후 PDF로 확인 필요)
